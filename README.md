# Wiki Timeline

Remettez cinq événements tirés de Wikipédia dans l’ordre chronologique.

**Jouer : https://kevinraphael95.github.io/wikitimeline**

## Règles

- Glissez les cartes (par la poignée sur mobile) ou utilisez les flèches ↑ ↓ au clavier.
- Du plus ancien en haut au plus récent en bas, puis **Valider**.
- Une carte est juste si elle est dans le bon ordre par rapport aux autres.

## Modes

| Mode | Événements |
|---|---|
| Facile | Articles très consultés |
| Normal | Articles assez connus |
| Difficile | Aucun filtre |

## Technique

HTML, CSS et JavaScript, sans dépendance. Données : API Wikipédia (« Ce jour-là » et statistiques de consultation). Thème clair/sombre, statistiques sauvegardées dans le navigateur.
